# DescubriendoPHP2Shelll

Publicación técnica sobre investigación y análisis del incidente PHP2Shell. Frontend construido exclusivamente con Angular (sin React, Vue, backend ni frameworks de UI externos).

## Requisitos

- Node.js compatible con Angular 21.
- npm.

## Ejecutar

```bash
npm install
npm start
```

Abre `http://localhost:4200`.

## Compilar

```bash
npm run build
```

## Incluye

- Angular standalone components y Angular Router.
- Interfaz responsive en tonos claros, con modo oscuro.
- Navegación, búsqueda local, filtros, checklist de mitigación y herramientas para documentación forense.
- Fuentes oficiales enlazadas y advertencias explícitas cuando los datos del incidente requieren verificación.

> Proyecto informativo. Verifica los datos específicos del incidente y las recomendaciones con fuentes primarias antes de usarlos para tomar decisiones operativas.
